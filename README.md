# 지역별 주유소 데이터 도구

주유소 정보와 판매가격 CSV를 브라우저에서 처리하는 정적 웹앱입니다.

- **지역 데이터 추출**에서 두 CSV를 불러오고, 지역을 선택해 자료를 각각 저장합니다.
- **지도에서 주유가격 조회**에서 두 CSV를 불러오고, 마커나 주유소 목록을 선택해 날짜별 유종 가격을 확인합니다.

저장소를 내려받아 `index.html`을 열면 오프라인에서도 사용할 수 있습니다. 파일로 직접 여는 경우 지도 화면에서 저장소에 포함된 행정동 경계 GeoJSON을 선택합니다. 입력 CSV는 사용자가 준비하며 브라우저에서 처리합니다.
